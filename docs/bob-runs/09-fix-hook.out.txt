## What was done

### Root cause confirmed
The old hook ran `node --test test/*.test.js` without `--test-reporter=tap`. Inside Bob (where `FORCE_COLOR` is set), Node uses the **spec reporter** which emits ANSI-coloured lines like `ℹ pass 29` instead of TAP `# pass 29`. The fallback regex looked for `passed:` which never appears in either format → always 0/0.

#### [`test/hook.test.js`](test/hook.test.js) *(new)*
9 tests covering three input formats — confirmed **red** before the fix (1 test file failed: `Module not found: summarize.cjs`):
- TAP multi-line (`# pass N` / `# fail N`) — pass count, failure names, ≤3 cap
- Old single-line comma format (`# tests N, pass P, fail F`)
- ANSI spec-reporter (stripped `ℹ pass N`, failure names from `✖ name` lines)

#### [`.bob/hooks/summarize.cjs`](.bob/hooks/summarize.cjs) *(new)*
