Cause to verify: on this Node version, node --test prints its TAP summary as separate lines ("# tests 29", "# pass 29", "# fail 0"), not "# tests 29, pass 29, fail 0", and the fallback regex looks for "passed:" which never appears.

2. Write test/hook.test.js (node:test, node:assert) that FIRST fails against the current logic: feed it a real TAP sample with "# pass 29" / "# fail 0" lines and expect "tests: 29 passed, 0 failed"; a sample with 2 failures expects the names; also keep the old single-line format working. Run `npm test` and show the failure before the fix.

Keep commands simple (npm test, node, cat). Do not touch index.js, index.html, src/ or other tests.
