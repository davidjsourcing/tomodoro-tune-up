## What was implemented — issue #11 Spoken Reminders

### [`src/speech.js`](src/speech.js) — new file
Pure helper module exposed as `window.TomodoroSpeech` with CommonJS tail for Node tests:

- **[`shouldSpeak(secondsLeft, totalSecs, intervalMins)`](src/speech.js:13)** — returns `true` only when `intervalMins > 0`, `0 < secondsLeft < totalSecs`, and `secondsLeft` is an exact multiple of `intervalMins * 60`.
- **[`reminderText(secondsLeft, round)`](src/speech.js:23)** — builds e.g. `"10 minutes left in your focus round"`, with singular `"minute"` for exactly 1.
- **[`transitionText(nextRound)`](src/speech.js:38)** — returns one of the three fixed transition phrases.
- **[`speak(text, synth)`](src/speech.js:51)** — no-op returning `false` if `synth` is falsy; otherwise cancels any queued speech, creates a `SpeechSynthesisUtterance`, and calls `synth.speak()`.

### [`test/speech.test.js`](test/speech.test.js) — new file
27 tests covering every branch: `intervalMins=0/-5`, boundary `secondsLeft=0/totalSecs`, multiples at 1/5/10/30 min, non-multiples, all three round labels, singular/plural, all three transition phrases, `speak` with `undefined`/`null`, and `speak` with a fake synth verifying cancel-before-speak.
